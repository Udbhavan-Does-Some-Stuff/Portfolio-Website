Multi-agent trajectory prediction

2026 — Finalist, MAHE Mobility Challenge Hackathon

A multimodal transformer that predicts six seconds of motion for several road agents at once, from three seconds of scene history, trained and evaluated on nuScenes.

1.30 mAverage displacement error
1.98 mFinal displacement error
  • Uncertainty-weighted losses, so the model is penalized in proportion to how confident it claimed to be.
  • An agent-aligned pseudo-Frenet transformation that regularizes longitudinal and lateral jerk, keeping predicted paths physically plausible.
  • No heavy HD-map processing, so it stays useful on the roads that detailed maps don’t cover, or cover badly.

PyTorch · nuScenes · multimodal transformers · kinematic regularization

Connectivity-aware routing

2026 — personal project

A routing platform that plans journeys over real road networks against three objectives: strongest cellular connectivity, fastest travel time, or a hybrid of the two. Shipped as a web application and as an automotive infotainment-style dashboard.

  • Graph-based pathfinding over OpenStreetMap road networks, exposed through a REST API.
  • SQLite caching for map tiles and cellular tower data, so repeated queries stop re-fetching the same geography.
  • Interactive route visualization in Leaflet, with the dashboard built to the constraints of an in-car display.

Python · FastAPI · NetworkX · OSMnx · SQLite · React · TypeScript · Leaflet

Aether

Independent — a 3D simulation environment for autonomy

A simulated robot and drone that perceive a 3D world, localize themselves, plan trajectories and navigate, running on an autonomy stack written from scratch in C++ rather than assembled from an existing framework.

  • Perception builds a representation of the scene.
  • Localization estimates where the agent actually is.
  • Planning chooses a trajectory through it.

C++ · physics simulation · planning · perception

Aftertime

A temporal memory layer for LLM assistants. It keeps facts across conversations and notices when they go stale or contradict each other, such as a deadline that moved or a project that finished. Each fact carries its source, verification date, expiry and replacement history, so the assistant can ask rather than answer from a memory it shouldn’t trust.

Python · FastAPI · SQLite · React · TypeScript · Gemini API

RENITO

An orchestration layer for teams running local coding agents such as Codex and Claude Code on different parts of one feature, then integrating the results into a single tested pull request. Built around agent memory and context handoffs, approved interface contracts, isolated Git worktrees, and test results tied to commit SHAs.

Python · FastAPI · PostgreSQL · React · MCP · Git worktrees
